# Журнал учителя

Расписание пар, план недели, списки классов, дела и копилка приёмов — в одном
приложении. Работает в браузере, ставится на компьютер и телефон, работает без
интернета.

**Открыть:** https://artemvdovenko2025-ux.github.io/zhurnal/

## Установка

- **Компьютер (Chrome или Edge):** откройте ссылку и нажмите «Установить» в адресной
  строке или кнопку ⤓ в шапке приложения.
- **iPhone:** Safari → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome → ⋮ → «Установить приложение».

## Где хранятся данные

Только на устройстве и — если включить синхронизацию — в папке «Приложения»
на Яндекс.Диске самого пользователя. На этом сайте и в этом репозитории личных
данных нет.

## Для разработки

Исходник — `src/app.src.html`. Сборка из папки `src`: `python3 build.py`, затем
`node icons.js`; готовый сайт появляется в `src/out/site/`. Личные файлы
(`private.json`, `rosters.private.js`) в репозиторий не попадают.
